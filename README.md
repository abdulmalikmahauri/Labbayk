# Labbayk Tour Curators

Макет сайта-каталога кураторов Labbayk Tour для паломников.

## Просмотр макета

Живая версия на GitHub Pages: https://abdulmalikmahauri.github.io/Labbayk/

Репозиторий: https://github.com/abdulmalikmahauri/Labbayk

## Что внутри

- главная страница с кратким объяснением роли кураторов;
- карточки кураторов с фото-плейсхолдерами, ролью, специализацией, опытом, языками и описанием помощи;
- подробный профиль куратора в модальном окне;
- аккуратный спокойный стиль с исламской тематикой без неуместных символов;
- адаптация под мобильные устройства.

## Важно по данным

Точные данные кураторов не были достоверно получены из публичного Instagram-предпросмотра, поэтому в макете стоят явно обозначенные временные данные. Их можно заменить на реальные ФИО, фото, опыт и языки после утверждения.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```
